# Demo Samples

This folder contains the static assets used by the GitHub Pages demo.

- `northern-cardinal.wav` and `heavy-traffic.wav` are copied from `quiet_horizon/test_data/`
- The matching `.json` files are precomputed QuietHorizon predictions generated locally
- `ATTRIBUTION.txt` preserves the original sample attribution notes

The public site uses these files to provide a transparent demo without requiring a live inference API.
