QuietHorizon

Static demo for an environmental audio classifier

This page is a transparent GitHub Pages demo. It does not run the model live in your browser. Instead, it replays two precomputed predictions generated locally from the QuietHorizon model.

View repository Get model from Hugging Face

What you are seeing

Select one of the bundled recordings below. The site loads a stored JSON result and the matching sample audio file from this repository. That keeps the public demo free, stable, and honest about what is happening.

Run it yourself

          
Use your own files locally

        

      


      

        For custom audio, clone the repository and run the real app or CLI locally. The pretrained model is available
        from Hugging Face.
      


      

        

          
Streamlit app

          
git clone https://github.com/bbureau12/QuietHorizon.git
cd QuietHorizon
pip install -e .
pip install -r frontend/requirements.txt
streamlit run frontend/app.py

        


        

          
CLI inference

          
git clone https://github.com/bbureau12/QuietHorizon.git
cd QuietHorizon
pip install -e .
python -m quiet_horizon.inference_cnn your-audio.wav --audio
